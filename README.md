# 제목 : 냠냠 프로젝트 BACK

## 팀원 : 김예진, 전제은

### 프로젝트 : JAVA, STS, Tomcat ....
### 프로젝트 시작 방법
- NyamNyamCoach_Back을 받을 빈 폴더를 하나 만든다.
- 만든 빈 폴더 안에서 git bash를 열고 git clone <repo 주소>
- metadata와 NyamNyamCoach_Back이 같은 위치에 있으면 된다.
- sts로 NyamNyamCoach_Back을 열고 server 설정.
- git은 NyamNyamCoach_Back 폴더 안에서 관리.

### 작업 방식
- git에서 아래 `branch 이름 규칙`에 따라 branch를 생성.
- 해당 브랜치로 이동 후 그 안에서 작업
- 작업 완료 후 PR 보내기
- 코드 확인 후 merge 하기
- github에서 branch 삭제하기
- 로컬에서 branch 삭제하기
- master pull 받기
- 이하 반복.

### branch 이름 규칙

`ex) feat/UserDto`

 - chore : 파일 삭제, 이동 같은 잡일 했을 경우
 - create : 파일 생성
 - feat : 기능 개발 + 기능 수정(에러 없는데 수정하는 경우)
 - debug : 기존 기능 에러가 있을 경우에 수정

### commit 규칙

`ex) chore : ㅇㅇ 파일을 삭제했습니다.`

 - chore : 파일 삭제, 이동 같은 잡일 했을 경우
 - create : 파일 생성
 - feat : 기능 개발 + 기능 수정(에러 없는데 수정하는 경우)
 - debug : 기존 기능 에러가 있을 경우에 수정
